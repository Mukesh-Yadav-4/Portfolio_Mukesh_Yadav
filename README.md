## 🌟 Highlights

- **Live Cardiac Telemetry Hero:** Real-time 60 FPS HTML5 Canvas Lead-II ECG waveform animation.
- **Featured Publication Spotlight:** Full showcase of *Personalized ECG & HRV Dynamics for Acute Stress Detection* with CERN Zenodo DOI, 15-fold LOSO metrics, baseline formula ablation, and 1-click BibTeX citation copy.
- **Modular Project Architecture (`src/data/projects.ts`):** Easy extensibility to push new projects one-by-one.
- **Vercel Zero-Config Deployment:** Optimized for instant global CDN deployment.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```

## 🌐 Deploy to Vercel (1-Click)

1. Push this repository to GitHub:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Mukesh Yadav Research Portfolio"
   git branch -M main
   git remote add origin https://github.com/Mukesh-Yadav-4/portfolio.git
   git push -u origin main
   ```
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import `Mukesh-Yadav-4/portfolio` and click **"Deploy"**.
4. Your website is live worldwide with free automatic HTTPS!
